# 智能客服之需求分析

## 一期：智能助手
 - 通过智能问答，为用户提供快速准确的信息查询和问题解答服务

 - 功能参考

|   参考平台   |   地址   |
| :--: | :--: |
|   OpenAI的ChatGPT平台   |   https://chat.openai.com/   |
|   阿里巴巴的通义千问平台   |   https://tongyi.aliyun.com/qianwen   |
|   深度求索的DeepSeek平台   |  https://chat.deepseek.com/    |
|   月之暗面的Kimi平台   |   https://kimi.moonshot.cn/   |

### 功能需求梳理
 - 用户登录、退出登录
 - 新建会话窗口/进入历史会话窗口
 - 选择是否深度推理或联网搜索
 - 如果选择深度思考，希望展示思考过程和思考状态
 - 如果选择联网搜索，希望列出来搜索了哪些网页，同时右侧支持点击网页超链接
 - 智能助手提供问题的详细回答
 - 上传文件，并且基于这个文件进行处理或回答

## 二期: 智能客服
 - 通过智能问答，高效解答用户问题、提升服务体验并降低人工成本
